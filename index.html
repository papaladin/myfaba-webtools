Créez vos propres histoires pour Faba

Cet outil convertit vos fichiers audio au format Faba Box — sans installation, sans compte, sans envoi de données.

CE DONT VOUS AUREZ BESOIN
Un ordinateur (Mac, Windows ou Linux)
Un Faba Box — la boîte rouge classique (offline) Pas compatible avec Faba+
Un câble USB-C pour connecter la Faba à votre ordinateur
Des puces NFC vierges type NTAG213 Moins de 1 €/puce sur Amazon ou AliExpress · App gratuite "NFC Tools" sur votre téléphone
Vos fichiers audio (.mp3, .wav, .ogg…) Uniquement des contenus dont vous êtes propriétaire
⚖️ Cet outil est destiné à vos propres contenus audio. N'utilisez pas de contenus protégés par le droit d'auteur. Aucun fichier n'est envoyé sur internet — tout se passe dans votre navigateur. Cet outil n'est pas affilié à MyFaba.
Étape 1 sur 3

Choisissez un numéro de figurine

Ce numéro identifie votre histoire sur la Faba Box. Nous en avons choisi un pour vous — vous pouvez le garder ou en choisir un autre.

2742
Numéro de figurine

Les nombres entre 2000 et 8999 n'entrent pas en conflit avec le contenu officiel de Faba. Assurez-vous que l'ID choisi n'est pas déjà utilisé par du contenu que vous avez déjà importé dans votre Faba.

Ajoutez vos fichiers audio

Vous pouvez ajouter plusieurs fichiers — ils deviendront les pistes de votre histoire, dans l'ordre que vous définissez.

    Votre fichier est prêt !

    Suivez ces étapes pour installer votre histoire sur la Faba Box.

    1. 1
      Décompressez le fichier téléchargé

      Vous trouverez un dossier nommé K???? à l'intérieur.

    2. 2
      Connectez votre Faba Box

      Branchez-la en USB-C à votre ordinateur pendant qu'elle est allumée. Elle apparaît comme une clé USB.

    3. 3
      Copiez le dossier sur la Faba

      Glissez K???? à la racine du lecteur Faba. Ne le renommez pas.

    4. 4
      Éjectez et débranchez

      Éjectez proprement le lecteur avant de débrancher le câble.

    5. 5
      Programmez votre puce NFC

      Ouvrez NFC Tools sur votre téléphone. Appyuez sur Écrire → Ajouter un enregistrement → Texte et entrez exactement :
      02190530????00
      Appuyez sur Écrire, puis approchez votre puce NTAG213 de votre téléphone.

    6. 6
      Posez la puce sur la Faba Box

      Allumez votre Faba Box et posez la puce NFC dessus. Votre histoire devrait démarrer !
